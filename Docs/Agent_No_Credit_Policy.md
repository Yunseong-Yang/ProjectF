# ProjectF — 에이전트 크레딧 사용 금지 정책

- 정책 버전: 1.0
- 적용일: 2026-10-29, Asia/Seoul
- 근거: 사용자의 "에이전트에게 맡김에 있어서 크레딧은 절대 사용하지 않도록" 요청
- 기본 동작: **NO_CREDIT — 비용이 있거나 불명확한 실행은 하지 않는다.**
- 프로젝트 기획: [게임 상세 기획 및 개발 계획](ProjectF_Design_and_Development_Plan.md)

## 1. 금지 범위

ProjectF 작업자는 다음 행동을 실행하지 않는다.

1. 보유 유료 크레딧, 무료 체험 크레딧, 프로모션 크레딧을 차감하는 모델·이미지·3D·애니메이션·음성 생성.
2. 사용량 기반 과금 API 호출. 계정에 API 키나 잔액이 있다는 사실은 실행 허가가 아니다.
3. 유료 생성 웹사이트, 호스팅된 Tripo/Kimodo 대행 서비스, 클라우드 GPU·렌더팜·유료 변환 서비스.
4. 에셋·플러그인·소프트웨어 구매, 유료 구독 시작·업그레이드, 크레딧 구매·충전·자동 충전 활성화.
5. 무료처럼 보이지만 종료 후 과금되거나 별도 크레딧이 감소하는 체험 작업.
6. 로컬 실패·할당량 소진을 이유로 유료 API·클라우드·다른 모델·다른 계정으로 자동 전환.
7. 하위 에이전트 생성, 별도 모델 API 호출, 자동 클라우드 채팅, 백그라운드 AI 검토 등 추가 모델 작업의 자동 위임.
8. 장시간 반복 작업·예약 실행·재시도를 통해 비용 여부가 불명확한 서비스를 계속 호출.
9. 비용을 줄였다는 이유만으로 "크레딧을 사용하지 않았다"고 보고하는 행위.
10. 이 정책을 구현했다는 이유로 계정 전체의 과금 차단이 완료됐다고 주장하는 행위.

유료 크레딧을 이미 구매했거나 무료 크레딧이 남아 있어도 사용하지 않는다. 결제액 0원과 크레딧 차감 0은 같은 조건이 아니다.

## 2. 허용 가능한 기본 경로

| 작업 | 기본 경로 | 확인 사항 |
|---|---|---|
| 코드·문서 편집 | 현재 사용자가 시작한 작업에서 로컬 파일 편집 | 추가 모델·API 작업을 시작하지 않음 |
| Unreal 빌드·테스트 | 로컬 도구 | 외부 유료 빌드·분석 서비스 없음 |
| Blender 작업 | 로컬 Blender와 로컬 스크립트 | 유료 생성 애드온·클라우드 렌더 비활성 |
| 신규 형상 | 로컬 TripoSG | 실제 추론이 로컬인지, 숨은 원격 호출이 없는지 |
| 신규 동작 | 로컬 Kimodo v1.2 | 로컬 추론·로컬 변환, 유료 대행 미사용 |
| 기존 동작 | 이미 보유한 파일 또는 Mixamo의 크레딧 차감 없는 제공 경로 | 현재 다운로드가 결제·크레딧을 요구하지 않는지 |
| Fab 에셋 | 이미 소유한 상품의 이용 가능한 다운로드 | 상품 소유·이용 조건·새 구매 없음 |
| 모델 파일·라이브러리 다운로드 | 공개 또는 사용 권한이 있는 무료 파일 다운로드 | 원격 추론·유료 저장소 생성과 구분 |
| 문서 조사 | 공개 문서·공식 자료 읽기 | 구매·유료 API 실행과 구분 |

로컬 도구도 외부 서비스를 호출할 수 있으므로 "로컬에서 실행한 프로그램"이라는 이유만으로 무료라고 판단하지 않는다. 로컬 장비의 전력·장비 비용까지 0원이라는 뜻은 아니다.

## 3. 실행 전 판단 절차

1. 도구가 실제로 수행할 동작을 확인한다: 파일 읽기, 로컬 계산, 다운로드, 원격 추론, 구매, 자원 생성 등.
2. 서비스가 필요한 경우 크레딧·과금·자동 전환 여부를 확인한다. 불필요한 비밀키나 결제 정보를 수집하지 않는다.
3. 크레딧 차감 또는 과금이 확인되면 실행하지 않는다.
4. 비용 경로를 확인할 수 없으면 해당 동작을 실행하지 않는다.
5. 로컬 도구·기존 에셋·수작업·무료 블록아웃으로 대체한다.
6. 대안이 없으면 해당 부분을 미완료로 기록하고 다른 가능한 작업을 진행한다.

일반적인 "계속해", "알아서 해", "에이전트에게 맡겨"는 이 금지 정책의 해제가 아니다. 사용자가 나중에 비용 정책을 명시적으로 변경하기 전에는 비용 발생 경로를 사용하지 않는다. 금지 경로를 쓸 수 있게 해달라는 결제 권유를 반복하지 않는다.

## 4. 에이전트 위임

기본은 현재 사용자가 직접 시작한 단일 작업자가 수행한다.

- 이 문서를 읽었다는 이유로 다른 AI 작업자나 별도 대화를 자동 실행하지 않는다.
- "로컬 에이전트"라는 이름도 모델 API 비용이 없다는 증거가 아니다.
- 여러 단계를 수행하는 결정적 로컬 스크립트는 AI 하위 에이전트와 구분한다. 외부 추론을 하지 않는 빌드·검사·변환 스크립트는 허용할 수 있다.
- 사용자에게 작업을 넘기거나 후속 작업을 준비할 때 이 정책 경로, 적용 범위, 실행하지 않은 항목을 전달한다.
- 하위 에이전트를 무료라고 추정해 실행하는 예외는 두지 않는다.

## 5. Codex 자체 사용량과 강제 차단의 한계

OpenAI 공식 안내는 포함 사용량과 추가 크레딧을 구분한다. 계정·플랜에 따라 포함 한도 이후 크레딧이 사용되거나 크레딧 기반으로 사용량이 계산될 수 있다. API 키 사용은 별도의 API 요금 경로다.

**이 Markdown과 AGENTS.md는 에이전트 행동 규칙이지, 계정 과금 시스템의 기술적 차단 장치가 아니다. 현재 대화 자체의 모델 사용량을 0으로 만들거나 계정 크레딧 차감을 강제로 막을 수 없다.**

따라서 다음을 지킨다.

- Codex 계정의 실제 과금 차단을 설정·검증하지 않았다면 그렇게 보고한다.
- 지원 여부를 확인하지 않은 `no_credits=true` 같은 설정을 만들어 효력이 있다고 주장하지 않는다.
- 포함 사용량이 없거나 크레딧 사용이 요구되는 상황을 확인하면 추가 AI 실행·위임·재시도를 시작하지 않는다.
- 사용 한도에 도달해도 API 키·다른 계정·추가 구매로 우회하지 않는다.
- 새로운 장시간 자동 작업을 무과금이라고 전제해 예약하지 않는다.
- 기존의 다른 작업·계정 자동화·결제 설정을 이 문서 작성만으로 변경했다고 간주하지 않는다.

계정 수준의 절대 차감 금지가 필요하면 해당 계정에서 제공하는 관리자·사용량·지출 제어를 별도로 확인해야 한다. 이 작업에서는 계정 과금 설정을 변경하거나 차감 0을 검증하지 않았다.

## 6. 작업 결과 보고

보고 항목:

- 실행한 로컬 도구와 사용한 기존 에셋.
- 외부 서비스가 있었다면 실제 수행한 읽기·다운로드·실행의 종류.
- 금지하거나 무료 경로로 대체한 작업.
- 생성·구매·클라우드 자원·추가 모델 작업을 실행했는지 여부.
- 확인하지 못한 비용과 계정 과금 상태.

에이전트가 추가 과금 작업을 시작하지 않았다는 기록과 계정 전체 크레딧 차감 0이라는 주장은 구분한다. 후자는 계정 측 증거 없이 선언하지 않는다.

## 7. 이 정책의 현재 적용 상태

- 정책 문서 작성: 완료.
- 프로젝트 루트 AGENTS.md에 정책 연결: 완료.
- 유료 API·생성 크레딧·구매·클라우드 자원·자동 하위 에이전트 금지: 작업 지침으로 적용.
- 계정 과금·추가 크레딧 사용 차단: 미설정·미검증.
- 현재 대화의 모델 사용량: 호스팅 제품이 관리하며 이 문서에서 0으로 보장하지 않음.
