### 자동 시험에서 다룬 규칙

- 협동 인원별 체력·공격력·병력 보정과 전투 중 배율 고정.
- 요청 중복·역순·번호 순환.
- 개인 스킬 선행 조건·중복·프로필 범위, 보상 중복 방지.
- 아군 직접 피해 거절, 다운·소생·사망, 체력과 독립된 처형.
- 같은 적 예약 독점, 처치 ID 유지, 후방 방향, 벽에 막힌 처형 거절.
- 유효 소총 헤드샷, 산탄 한 발의 치명 처치 예외, 헬멧 우선 처리.
- 회복·재장전 취소의 자원 보존, 사망·복원 시 탄약 재충전 방지.
- 생존 적 언로드를 처치로 세지 않는 병력 기록.
- 적의 시야와 단단한 엄폐를 고려한 안전 스폰.
- 가벼운 피격이 자동 사격 입력을 끊지 않음, 다운 시 오래된 질주·조준 입력 해제.
- 첫 피해를 차감하기 전에 협동 체력 보정을 확정함.
- 저장 임시 파일·CRC·이전 정상본, 손상된 현재 파일에서 백업 복구.

협동 시나리오는 처형 동시성과 저장을 분리 검증하기 위해 순찰 관찰 후 관련 없는 적 AI를 정지하고, 남은 병력을 서버에서 정리한 뒤 점령을 시험한다. 이 결과는 잠입·정면 교전으로 거점을 자연스럽게 완주했다는 증거가 아니다.

## 성능 판정

전체 판정은 **미승인**이다. 계측 안정성 실패가 있고, 요구한 생산 규모의 시나리오 증거가 없다.

테스트 장비에서 확인된 값은 i5-13600K, RAM 약 32GB, RTX 3060 Ti 8GB다. 최소·권장 사양을 확정한 것이 아니다.

- 목표 예산은 기획의 임시 기준을 유지한다: 1080p 중간 품질, 클라이언트 p95 16.7ms / p99 25ms, RAM 8GiB / GPU 메모리 5GiB, 서버 p95 33.3ms.
- 제한된 캡처는 안전 캠프의 1인, 원거리 적 16개, HUD·메뉴, 화면 외 렌더링이다. 시작 구간과 계측 오버헤드가 포함된다.
- 단독 계측 시도의 600프레임 관찰값: 프레임 p95 약 7.95ms / p99 약 8.60ms, 최대 약 3,584ms. 최대값은 시작 구간을 포함하므로 별도로 보존하며 숨기지 않는다.
- 같은 시도에서 프로세스 최대 Working Set 약 2.29GiB, GPU 전체 장치의 표본 최대 약 3.59GiB를 관찰했다. GPU 값은 다른 앱도 포함하고 표본 사이의 최대값을 보장하지 않는다. Private Bytes는 실제 RAM과 같다고 계산하지 않는다.
- 일반 실행 종료 코드 0을 별도로 확인했다. CSV·Trace 또는 메모리 계측을 사용한 실행에서는 코드 777003이 관측됐다. 설치 엔진의 해당 값은 `CrashReporterCrashed`에 대응하지만, 근본 원인은 확정하지 않았다. 원본 로그·CSV·Trace를 보존했다.
- 4인 밀집 + 주둔 14 + 증원 4, 두 거점의 2+2 분산, 승인 아트·애니메이션, 장시간 반복의 RAM/VRAM·프레임·대역폭은 미측정이다.
- 권한 규칙·AI·저장은 CPU, 렌더링은 Unreal의 GPU 경로를 사용한다. 이 배치가 전체 성능 합격을 뜻하지 않는다.

자료: `Saved/Implementation/20261029_FullPlan/Profile/`, `clean-exit.json`, `csv-exit.json`.
