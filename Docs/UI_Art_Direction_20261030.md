# ProjectF 화면 구성 기준

이번 이어서 작업의 현장 진입 화면에 적용한다. 출시 승인이나 파크라이 4 수준을 달성했다는 기록은 아니다.

## 방향

산악 지역의 실제 장면을 배경으로 두고 왼쪽에서 이어하기, 방 열기, 참가, 설정, 종료를 고른다. 장식용 수치나 판매 페이지 구성은 사용하지 않는다. 시작을 선택하기 전에는 개인 프로필의 서버 등록과 플레이어 생성을 진행하지 않는다.

색은 숲 `#263D32`, 짙은 그늘 `#172522`, 밝은 안개 `#D8E3DE`, 황토 `#D4AE63`, 흐린 녹색 `#9DB0A4`를 기준으로 한다. 게임 내부의 선형 색 값과 화면 변환 때문에 수치는 직접 대응하지 않는다. 선택한 버튼은 황토 바탕과 짙은 글자로 구분한다. 일반 버튼은 밝은 글자를 사용한다. 실제 화면에서 읽힘을 확인한다.

타이틀에는 설치된 Unreal 기본 글꼴의 큰 서체를, 한글 설명과 동작에는 엔진의 한글 대체 글꼴을 사용한다. 새 글꼴 다운로드는 없다. 1280×720의 메뉴 구성 영역을 화면 비율에 맞춰 축소·확대한다. 자동 카메라 이동이나 장식 애니메이션은 넣지 않는다.

## 검토와 수정

초기 자료 검색의 일반 웹 홍보 화면 추천은 게임 진입 동선과 맞지 않아 적용하지 않았다. 게임용 검색에서도 네온 배색과 판매용 기능 카드가 추천됐으나 산악 현장과 맞지 않아 채택하지 않았다. 실제 3D 배경, 읽기 쉬운 대비, 보이는 키보드 초점, 뒤로 가기 원칙만 참고했다.

첫 촬영에서 모든 버튼의 흰 테두리와 화면 아래로 밀리는 안내를 확인했다. 버튼 높이를 줄이고 단색 바탕으로 바꿨으며 초점 버튼의 글자를 어둡게 수정했다. 초기 입력 모드가 첫 버튼의 초점을 덮어쓰는 문제도 수정했다.

## 검증 범위

로컬 실행에서 시작·참가·설정 화면을 촬영하고 이어하기 후 프로필, 플레이어, HUD 생성과 시작 위젯 정리를 검사한다. 실제 물리 게임패드의 전체 탐색과 모든 해상도·UI 크기 조합은 아직 승인하지 않았다. 개발 검사에서 직접 버튼 동작을 호출한 사실을 키보드·게임패드 실사용 검증으로 바꾸어 기록하지 않는다.
