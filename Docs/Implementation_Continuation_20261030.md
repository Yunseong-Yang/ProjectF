## 환경·모델·음향

이미 로컬에 내려받은 Epic Content Examples, Slay, Game Animation Sample, Lyra의 선택한 에셋을 사용했다. 외부 원본은 보존하고 필요한 의존성과 출처·해시를 기록했다. 현재 계정의 Fab 구매 내역을 별도로 인증하지 않았으며, 공개 Epic 샘플의 이용 허용 근거와 UE 전용 제한을 기록했다. 원래 게임·캐릭터 이름을 ProjectF의 마케팅 이름으로 사용하지 않는다.

- 환경: 원본 수출 → Blender 정리·감면 → 별도 파생 FBX → Unreal 수입, 재질·LOD·충돌 검사. `ArtSource/Environment/`에 기록.
- 지형: 64개 타일, 총 204,800개 삼각형. 경로와 시설의 평탄부를 유지하면서 산의 세부 기복을 보강했다. 원거리 반복무늬를 줄이는 재질과 실제 삼각형 표면에 맞춘 배치를 사용한다.
- 지형 대조: 실제 충돌 128곳과 계산 높이의 최대 차이 약 0.0102cm, 허용 2cm 이내. 두 거점까지 네 구간의 완전한 이동 경로를 확인했다.
- 식생: 공간별 HISM 묶음에 저장하여 런타임에 전체 흩뿌리기를 계산하지 않는다. 풀은 짧은 표시 거리·그림자 제외, 나무는 줄기 충돌을 사용한다.
- 바위: 열린 스캔 절벽을 평지의 독립 바위로 사용하던 배치를 수정했다. 평지에는 닫힌 바위를 사용하며 단순 충돌 한 개와 500/250/90개 삼각형의 LOD를 기록했다.
- 사람형 적: 불필요한 원본 무기 면을 제거하고 얼굴·손 정점 20,568개를 보존했다. Blender 결과 60,000개 삼각형, 가중치 없는 정점 0. 실제 Unreal LOD는 60,000/14,998/7,499개 삼각형, 정점은 40,421/12,030/6,873개다.
- 사람형 적의 재질은 12개로 초기 목표 2~4개를 넘는다. 통합 또는 측정 근거가 있는 예외와 시각 승인이 필요하다. LOD를 만들었다는 사실만으로 승인하지 않았다.
- 애니메이션: 로컬 IK Retargeter로 아홉 개 이동·사격·재장전·사망 클립을 베이크했다. 손 소켓과 실제 머리 충돌을 검사했다. 최종 관절 변형·접지·접촉 검수는 남아 있다.
- 무기: 원본을 보존한 야전 마감 파생 모델, Blender 4,822개 삼각형·UV 두 개·퇴화 면 0, Unreal LOD 세 개. 최종 1인칭 아트 승인은 하지 않았다.
- 효과음: 로컬 계산으로 만든 사격·소음 사격·발소리·경보·피격 확인·탐지·바람 음원과 출처 기록. 성능 촬영에서는 소리를 껐으므로 음향 CPU 비용은 해당 측정의 승인 범위가 아니다.

프로토콜 3의 Editor 네 프로세스 검사와 package-development-06의 지연 75ms·손실 3% 검사가 통과했다. 사람형 적, 사격 표현, 탄약, 이동, StateTree 이동, 같은 적의 중복 처형 방지, 확보 동기화와 재접속을 포함했다.

이 협동 검사는 같은 PC의 별도 프로세스를 Loopback UDP로 연결한다. 점사는 손실로 인한 신뢰 입력 큐 압축과 표현 중복 방지를 구분하기 위해 서버의 고정 0.25초 구간도 사용한다. 남은 적의 정리는 통제된 절차이며 자연스러운 거점 플레이 완료를 증명하지 않는다. 실제 인터넷·별도 PC 검증은 남아 있다.

### 후속 진행: 기본 후방 타격 연출

위 package07 기준점 이후 소스와 최신 package08은 프로토콜 4다. package07은 프로토콜 3이다.

로컬에 보유한 Lyra 근접 동작 세 개를 격리 공간에 복사하고, 게임별 알림을 포함하지 않는 FBX로 내보냈다. 프로젝트 리그의 복사본에 가져오고 Blender에서 루트·손·발의 유한한 궤적을 검사했다. 0.35초의 소총 타격 손과 대상의 등뼈 거리는 약 16.25cm였다. 이 수치만으로 피부·무기 접촉이나 최종 연출을 승인하지 않는다.

기본 후방 타격에는 공격자·피격자의 공통 서버 시작 시각과 접촉 지연을 사용한다. 처치는 기존 서버 규칙으로 즉시 확정하며, 동작이 피해나 보상을 다시 발생시키지 않는다. 머리·체력·협동 배율 조건은 기존 처형 규칙과 분리해 유지한다. 서는 공간 검사, 끝난 뒤 앉기 복원, 조준 방해 차단과 다운 시 정리를 추가했다.

처음에는 1인칭 조준 보정이 타격을 덮어쓰는 화면을 확인했다. 처형 중에 실제 몸의 타격 그래프를 사용하고 일시적인 시야·목 표시 변경을 끝날 때 복구하도록 수정했다. 전신과 1인칭 연속 촬영은 정상 종료했고, Automation19에서 31개가 통과했다. 이후 효과음·원격 앉기 복원·조준 방해 차단과 임시 시야 복구 검사를 추가했고, Automation20에서 31개가 경고 없이 통과했다. 업데이트된 네 프로세스 Editor 검사도 통과했다.

package-development-08의 화면 검사 다섯 개, 네 프로세스 지연·손실 9개 조합과 성능 표본 세 개가 모두 정상 종료했다. 1080p 중간 품질의 밀집 p95/p99는 11.6643/12.9887ms, 분산은 11.3819/12.3943ms다. 프로세스 RAM은 표본 세 개 중 최대 약 2.22GiB, 샘플링된 전용 GPU 할당량은 약 2.29GiB였다. 전체 종류의 최종 처형 쌍과 카메라 품질은 미완료다. `Verification_Summary_package08.json`에 범위·한계·남은 일을 기록했다.

첫 검수 맵 저장에서 시작 지점이 빠지고 촬영 도구가 없는 캐릭터를 참조하는 오류를 확인했다. 명시적인 월드 저장과 빈 캐릭터 처리로 수정했고, 자료 준비 완료를 기다리는 촬영 경로를 추가했다. 실패 로그는 유지했다.

원본 장면의 `Terrain_TF0010`은 편집기·실행 모두 숨겨진 촬영용 대안이었다. 두 지형을 함께 불러 발생한 겹침을 확인하고 원래 표시되는 지형만 남겼다. 다만 지형만으로는 주요 바닥·건물 구성이 완전하지 않아 원래 배경과 조명을 포함한 `/Game/ProjectF/Maps/Tests/L_TempleArtReview`도 만들었다. 885개 액터의 장면 저장과 자료 준비를 기다린 실제 화면 촬영이 정상 종료했다.

추가 장면에서는 상세한 건축 구성을 확인했지만, 시작 지점의 실제 이동·건물 충돌·모든 사용 모델의 최적화와 프레임·메모리 검수가 남아 있다. 원본 건축 자료의 렌더링에는 Ray Tracing 상주 지오메트리 예산 경고도 표시됐다. 현재 자료를 플레이용 지형으로 승인하거나 기본 맵에 적용하지 않았다. 이 별도 화면을 현재 플레이 맵의 완성 화면으로 제시하지 않는다.

처음 검수 조합에서 배치가 있는 모델 49종을 수출하고 Blender에서 UV·법선·열린 면·퇴화 면을 검사했다. 기존 작가 LOD가 있으면 이를 우선 사용했고, 큰 나무는 약 16만 면에서 약 2만 면인 단계로 복사했다. 별도 모델로 수입하여 원점·크기를 비교했고 대부분 일치했다. 빠진 덤불 줄기 재질의 수선 내역도 기록했다. 이 검사만으로 모든 모델을 승인하지 않았으며, 특히 줄기 충돌·원본 장면 구성·실제 배치·게임 내 이동과 성능 검수가 필요하다.

이전 마네킹 기준 성능 수치는 이번 사람형 적·최종 환경의 합격 근거로 사용하지 않는다. GPU 메모리는 장치 전체를 1초마다 측정하는 방식이므로 프로세스 전용 최대 할당량과 구분한다. 이전 CSV 계측 종료 오류는 별도 프레임 기록 성공으로 해결 처리하지 않는다.

## 보존한 실패와 수정

- 사람형 메시를 NullRHI에서 수출할 때 엔진 `MeshObject` 검사 실패. RHI가 있는 로컬 수출로 진행했다.
- 초기 재질 마스크를 색으로 표시하던 문제, 가상 텍스처 샘플러와 무기 재질 사용 플래그, 카메라 좌표의 쉼표 해석, Python 회전 인수의 순서를 수정했다.
- 첫 사격 표현 협동 검사에서 지연 프레임 때문에 소총 탄수가 28발로 남는 실패를 보존했다. 발사 주기를 수정한 뒤 단위·네트워크 검사에서 재확인했다.
- 검사 도구가 Windows GUI 실행을 기다리지 않거나, 엔진이 저장 폴더 이름의 하이픈을 정리해 촬영 파일을 찾지 못한 경우를 보존했다. 실행 종료 대기와 안전한 폴더 이름을 사용하는 검사 도구로 변경했다.
- 앞선 `777003 / CrashReporterCrashed` CSV 종료 문제는 미해결이다.

1. 파크라이 4를 참고한 근접·원거리 아트의 실제 완성도 검수와 환경 구성 보강. 현재 산악 지형과 배치는 개발 후보이며 그래픽 기준에 도달했다고 평가하지 않는다.

4. 자연스러운 20~30분 탐험·정찰·잠입·교전·보급·재시도 플레이와 재미·난도 검수.

## 비용과 변경 추적

추가 모델 작업자, 별도 모델/API, 구매, 구독, 클라우드 생성·GPU 작업을 실행하지 않았다. 로컬 Blender·Unreal·결정적 스크립트와 이미 내려받은 에셋을 사용했다. Codex 계정 과금이나 크레딧 차감 0은 검증하지 않았다.

현재 요청 직전 상태와 비교한 전체 코드 패치는 `Saved/Implementation/20261030_Continuation/ProjectF_continuation.patch`, 파일별 요약은 `Code_Diff_Summary.md`다. 기존 원본 콘텐츠 542개의 해시를 별도 대조한다. 커밋·푸시·출시 배포는 하지 않았다.

마지막 보존 검사에서 원본 콘텐츠 542개와 기획·비용 정책 두 문서는 모두 유지됐다. 바이너리 에셋의 전후 식별값은 `asset-changes.json`에 별도로 기록한다. 출시 준비 검사 결과는 `release-readiness.json`이며 승인된 맵·모델이 없어 `release_allowed=false`다.
