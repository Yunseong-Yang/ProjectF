# ProjectF 실행과 조작

현재 결과는 프로토콜 4의 Windows Development 실행본이다. 최종 아트·모든 처형 연출·실제 인터넷 협동과 완성본 검수는 진행 중이다.

## 실행

최신 실행본은 `Builds/ProjectF_Development_Temple21/Windows/ProjectF.exe`다. 같은 폴더의 `사원 공략.lnk`는 사원 후보 맵을 바로 연다. 비교 기준으로 실행본 18(`Builds/ProjectF_Development_Temple18`)을 함께 보관한다. 이전 실행본은 2026-11-18에 정리했고, 그 안의 저장·검증 기록은 `Saved/Archives/RetiredBuilds_SavedData_20261118_164751.zip`에 있다.

`ProjectF.exe`를 실행한다. 시작 화면에서 **현장으로 · 이어하기**를 선택하면 자신의 진행으로 산악 캠프에 진입한다. **협동 방 열기**는 같은 월드를 최대 네 명이 참가하는 방으로 연다. 참가자는 같은 프로토콜의 실행본에서 **협동 참가**와 호스트의 IP 주소를 사용한다.

현재 검증은 같은 PC의 별도 프로세스와 로컬 연결 기준이다. 인터넷 초대·연결 제공자와 별도 PC는 최종 검증하지 않았다.

## 기본 조작

| 조작 | 기본 키 |
|---|---|
| 이동 | W / A / S / D |
| 사격 / 조준 | 마우스 왼쪽 / 오른쪽 |
| 질주 / 앉기 | Shift / C |
| 점프·낮은 장애물 넘기 | Space |
| 재장전 / 무기 교체 | R / Q |
| 상호작용·동료 소생 | E 길게 |
| 정찰 | B 누르기 |
| 유효한 테이크다운 | F |
| 회복 / 투척 | H / G |
| 작전 메뉴 | Esc |

작전 메뉴의 **화면·조작**에서 16개 게임 조작을 다시 지정할 수 있다. 이미 쓰는 키를 지정하면 기존 설정을 보존하고 안내한다. 조준·질주·앉기의 누르기/전환, 감도, 시야각과 화면 설정도 이곳에서 바꾼다. 협동 메뉴는 월드를 멈추지 않는다.

## 첫 활동

캠프에서 통신소의 위치를 확인하고, 도로와 우회 지형을 따라 접근한다. 정찰은 관찰한 정보를 공유하며 벽 뒤의 실제 위치를 계속 알려주지 않는다. 앉기와 엄폐로 탐지 시간을 벌고, 경보 장치를 해제하거나 파괴해 증원을 억제한다. 호출 중인 적은 제압할 수 있다.

거점의 위협을 제거한 뒤 시설에 접근해 E를 길게 눌러 확보한다. 통신소 확보는 주요 거점의 지원 관계에 영향을 준다. 탐험 보급품은 설계도를 제공하며 장비 제작은 안전 캠프나 확보한 안전 지점에서 한다. 회복 도구와 투척 도구, 탄약도 보급 자원을 사용한다.

기본 후방 처형은 비경계 적의 뒤에서 거리·시야·공간 조건을 만족할 때 표시된다. 서버가 유효하다고 확정하면 체력이나 협동 체력 배율과 무관하게 처치한다. 현재 기본 후방 타격 후보 동작은 연결돼 있으며 다른 종류의 최종 연출은 아직 미완료다.

## 저장과 종료

확보·보상은 서버의 진행에 저장된다. 호스트의 월드 진행과 개인 성장은 구분한다. 작전 메뉴의 **협동·저장 → 저장 후 나가기**를 사용한다. 저장에 실패하면 안내를 확인하며, 마지막 정상 저장을 보존한다. 강제 종료는 마지막 완료된 저장 이후 진행을 잃을 수 있다.
